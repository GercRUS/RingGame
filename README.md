# Ring Drop

Ритм-игра: шарик в центре, вокруг вращающиеся кольца с прорезями. Тапни, когда цвет шарика совпал с цветом ближнего кольца, прорезь шире шарика и находится под меткой внизу.

## Структура
- `www/index.html` — вся игра (HTML5 Canvas, один файл). Правишь здесь.
- `android/` — Android-проект Capacitor (иконка, сплэш, портретная ориентация уже настроены).
- `.github/workflows/build.yml` — сборка APK на GitHub Actions.

## Как собрать APK
1. Создай репозиторий на GitHub и залей туда все файлы из архива (с сохранением папок, включая скрытую `.github`).
2. Открой вкладку **Actions**. Сборка запускается сама после загрузки (или вручную: *Build Android APK → Run workflow*).
3. Через 3–6 минут открой завершённый запуск, внизу в **Artifacts** скачай `ring-drop-debug-apk`, распакуй zip.
4. Скопируй `app-debug.apk` на телефон и установи (разреши установку из неизвестных источников).

## Проверка в браузере
Открой `www/index.html` двойным кликом или выложи на GitHub Pages. Играет и там.

## Заметки
- Это debug-сборка: подписана отладочным ключом, для личного теста подходит. Для публикации в Google Play нужна release-сборка с собственным keystore.
- Иконка и сплэш лежат в `android/app/src/main/res/`. ID приложения: `com.gercrus.ringdrop` (в `capacitor.config.json`).
- Рекорд хранится в `localStorage` WebView и сохраняется между запусками.
